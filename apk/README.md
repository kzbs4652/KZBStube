# 📱 KZBStube APK Kurulum Dosyaları

Bu klasör, **KZBStube** Android uygulamasının en güncel kurulum (`.apk`) dosyalarını içerir.

---

### ⬇️ Doğrudan İndirme Bağlantıları:

- **En Güncel APK:** [KZBStube.apk](https://github.com/kzbs4652/KZBStube/raw/main/apk/KZBStube.apk) *(Tıklandığında doğrudan telefonunuza iner)*
- **GitHub Releases Alanı:** [Tüm Sürümler ve Güncellemeler](https://github.com/kzbs4652/KZBStube/releases)

---

### 📲 Telefona Nasıl Kurulur?

1. Yukarıdaki `KZBStube.apk` bağlantısına tıklayarak dosyayı telefonunuza indirin.
2. İndirilen dosyaya dokunun.
3. Eğer telefonunuz *"Bilinmeyen kaynaklardan uygulama yükleme"* uyarısı verirse, **"İzin Ver"** veya **"Bu kaynaktan izin ver"** seçeneğini işaretleyin.
4. **"Yükle"** butonuna basarak kurulumu tamamlayın ve KZBStube'u açın!
